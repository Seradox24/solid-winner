# Crónicas del Gremio

Juego web de gestión de un gremio de aventureros con interacción estilo novela visual.
Abre `index.html` en un navegador (sin dependencias).

- Acepta contratos, asigna equipos y elige el enfoque (cauteloso / estándar / audaz).
- Habla con tus miembros (según su personalidad) para ganar lealtad y desbloquear escenas personales.
- Recluta aspirantes tras una entrevista, mejora el gremio y gestiona gastos diarios.
- Eventos aleatorios con decisiones. Objetivo: llegar al Rango S (100 de prestigio) sin hundirte en deudas.
- Guardado automático en el navegador (localStorage).
